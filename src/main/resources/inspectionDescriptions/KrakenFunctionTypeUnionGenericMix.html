Reports a Function parameter or return type that mixes a union with a generic, such as <T> | String. The engine does not support that combination.

Mirrors kvf007 and kvf010 (kvf020/kvf021 for a declaration without a body). A plain union (Date | DateTime) and a plain generic (<T>[]) are both valid and are not reported. Neither is Foo<Bar>, which names a type rather than a generic.
